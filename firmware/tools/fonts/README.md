# UI fonts

Static instances fetched from Google Fonts, rasterized to 1bpp by `../gen_fonts.py`.

| File | Family | Use |
| --- | --- | --- |
| `DMSans-*.ttf` | DM Sans (opsz 14) | UI text, status bar, captions |
| `SourceSerif4-*.ttf` | Source Serif 4 (opsz 20/36) | Titles, wordmark |
| `SourceSerif4Display-*.ttf` | Source Serif 4 (opsz 60) | PIN digits, clock, temperature |
